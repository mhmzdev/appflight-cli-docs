Use this for CI/CD runners where you can't run `appflight login` interactively.

## Reference

| Variable | Description |
|----------|-------------|
| `APPFLIGHT_API_KEY` | API key. Takes precedence over the credentials file. |

## APPFLIGHT_API_KEY

```bash
export APPFLIGHT_API_KEY=appflight_xxxxxxxxxxxx
appflight upload --flavor stage
```

Create the key with [`appflight keys create --name <label>`](/commands/keys), then add it as a secret in your CI platform (GitHub Actions, GitLab CI, etc.). Use a key made this way rather than the one `login` mints for your machine — a later `login` rotates that one and would break the pipeline.

The key is scoped to your account — keep it out of version control, and if it leaks revoke it with [`appflight keys revoke <label-or-prefix>`](/commands/keys) and mint a replacement.
